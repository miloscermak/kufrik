# Sentin Kufřík — Příručka AI promptů pro manažery

## O projektu
Statická jednostránková webová příručka AI promptů pro manažery, vytvořená pro Sentin. Obsahuje praktické prompty, tipy a příběhy z praxe.

## Technický stack
- Čisté HTML + CSS + vanilla JavaScript (vše v jednom souboru)
- Font: Inter (Google Fonts)
- Hosting: Netlify (statický deploy)
- GitHub repo: miloscermak/kufrik

## Struktura
- `sentin-kufrik-prirucka.html` — hlavní (a jediný) soubor, obsahuje vše inline
- `index.html` — alias pro Netlify deploy

## Deploy
- Netlify deploy z main větve
- Publish directory: `/` (root)
- Žádný build step — čistě statický web
